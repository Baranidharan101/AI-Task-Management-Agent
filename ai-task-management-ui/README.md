# AI Task Management UI

The modern web user interface for the AI Task Management Agent, built with **Vite** and **Tailwind CSS**.

## Features
- **Conversational Command Bar**: Submit natural language prompts with sub-second feedback.
- **Dynamic Task Board**: Kanban-style status columns (Pending, In Progress, Completed).
- **Auto-Decomposition Integration**: Trigger AI subtask generation with one click.
- **Morning Productivity Briefing**: Real-time summary of overdue and high-priority items.
- **Adaptive Reinforcement Feedback**: Allows quick priority adjustments that train the agent's weighting algorithm.
- **Telemetry Display**: Live API connection health and round-trip execution latency badge.

## Development

```bash
# Install dependencies
npm install

# Start development server on port 5173
npm run dev

# Build production bundle
npm run build

# Preview production bundle
npm run preview
```
